# AsamBasa Lab – Team Structure & Collaboration Guide

## 1. Informasi Tim

**Nama Proyek:** AsamBasa Lab  
**Jenis Proyek:** Website Pembelajaran Kimia Interaktif  
**Target Pengguna:** Siswa SMA/MA Kelas XI dan Guru Kimia  
**Mata Pelajaran:** Kimia – Materi Asam dan Basa  
**Pendekatan Pembelajaran:** Guided Inquiry Learning (Inkuiri Terbimbing)  
**Platform:** Web Application  
**Teknologi Utama:** React 19, TypeScript, Vite, CSS

## 2. Tujuan Tim

Tim pengembang AsamBasa Lab bertanggung jawab merancang, membangun, menguji, dan memelihara platform pembelajaran kimia interaktif yang membantu siswa memahami konsep asam dan basa melalui materi digital, eksperimen virtual, visualisasi, kalkulator pH, kuis, dan refleksi pembelajaran.

Pengembangan dilakukan dengan memperhatikan:
- Kesesuaian materi dengan kurikulum Kimia SMA/MA kelas XI.
- Ketepatan konsep dan perhitungan kimia.
- Kemudahan penggunaan bagi siswa dan guru.
- Konsistensi desain antarmuka.
- Responsivitas pada desktop, tablet, dan smartphone.
- Aksesibilitas dan kenyamanan pengguna.
- Kualitas kode, keamanan, dan kemudahan pemeliharaan.

## 4. Penggunaan AI Coding Agent

Dalam pengembangan AsamBasa Lab, AI coding agent melalui Antigravity digunakan sebagai asisten pengembangan perangkat lunak.

AI coding agent membantu:
- Membaca dan memahami dokumentasi proyek.
- Menganalisis struktur kode yang sudah tersedia.
- Mengembangkan komponen dan fitur.
- Membantu memperbaiki bug.
- Melakukan refactoring kode.
- Memeriksa konsistensi desain.
- Membantu menjalankan pengujian proyek.
- Memperbarui dokumentasi teknis.

AI coding agent tidak menggantikan tanggung jawab manusia dalam memeriksa ketepatan materi kimia, mengambil keputusan desain, menyetujui perubahan, dan memvalidasi hasil akhir.

## 5. Aturan Kolaborasi dan Pengembangan

Seluruh anggota tim dan AI coding agent harus mengikuti aturan berikut:

1. Membaca dokumentasi proyek sebelum melakukan perubahan.
2. Menggunakan PRD.md sebagai acuan kebutuhan dan ruang lingkup produk.
3. Menggunakan Technical Design Document sebagai acuan arsitektur dan desain teknis.
4. Menggunakan User Flow Document sebagai acuan perjalanan pengguna.
5. Mengikuti AGENTS.md untuk instruksi pengembangan bagi AI coding agent.
6. Mempertahankan struktur proyek yang sudah ada kecuali terdapat alasan teknis yang jelas.
7. Tidak menghapus atau mengubah fitur yang sudah berjalan tanpa persetujuan.
8. Menghindari duplikasi komponen dan kode.
9. Memastikan setiap perubahan tidak merusak fitur lain.
10. Memperbarui AI_LOG.md setelah menyelesaikan pekerjaan penting.

## 6. Standar Kualitas Proyek

Setiap fitur yang dikembangkan harus memenuhi prinsip berikut:

- **Functional:** Fitur berfungsi sesuai tujuan.
- **Usable:** Mudah dipahami dan digunakan siswa maupun guru.
- **Responsive:** Dapat digunakan pada berbagai ukuran layar.
- **Accessible:** Memperhatikan aksesibilitas pengguna.
- **Consistent:** Mengikuti sistem desain AsamBasa Lab.
- **Maintainable:** Kode mudah dibaca dan dikembangkan.
- **Accurate:** Materi dan perhitungan kimia harus benar.

## 7. Alur Kerja Pengembangan

Alur kerja pengembangan proyek:

1. Memahami kebutuhan berdasarkan PRD.md.
2. Memeriksa alur pengguna melalui User Flow Document.
3. Memeriksa arsitektur melalui Technical Design Document.
4. Memeriksa instruksi proyek melalui AGENTS.md.
5. Menganalisis kode dan komponen yang sudah tersedia.
6. Mengimplementasikan fitur sesuai prioritas.
7. Melakukan pengujian dan perbaikan.
8. Memperbarui dokumentasi dan AI_LOG.md.
9. Melakukan pemeriksaan akhir sebelum perubahan dinyatakan selesai.
